**踩坑（详见 docs/progress.md 的「阶段 5 踩到的坑」，已写成技能
`~/.workbuddy/skills/isaac-sim-usd-scene/SKILL.md`）**

1. `Sdf.Layer.Export` 导到自己的路径会留空文件 → 自建 stage 用 `Save()`。
2. USD prim 名不能以数字开头（`00_frame` → `p00_frame`），报错信息完全看不出原因。
3. 独立 Isaac Sim 不把 PhysX 挂到 stage 上 → 必须 `activate_physics()`。
4. Kit 接管 `sys.stdout`，headless 下 `print` 被吞 → 报告写 `sys.__stdout__` + 文件。
5. `SimulationApp.close()` 会直接终止进程 → 先写文件再 `close()`。
6. YAML 1.1 浮点指数必须带符号（`2.4e+9`）。
7. 启动 `SimulationApp` 前要清空 `sys.argv`，否则参数被转发给 Kit。
8. `open_stage()` 会往内存图层塞 `/Render` + 4 个视口相机，导致同一文件报出 344 与 351
   两个 prim 数 → 验证跑临时副本 + 比对原文件 SHA-256。
