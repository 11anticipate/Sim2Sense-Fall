# 人体整改实施与验收，2026-09-25

本轮完成质量门、足底几何修正与数据边界整改；正常动作整体尚未通过，阶段 7 未完成，
阶段 8 批量数据/CIR 恢复仍阻塞。本文取代独立审查中的“只审查未改代码”作为本轮最新状态。

## 已落地

1. `humans/quality.py` 逐动作检查实际蒙皮足底、实际地面接触、无支撑持续时间、接触点滑速、
   关节误差和穿地。左右行走转向也单独检查；站立帧不能稀释行走/转向失败。
   门槛保留滑速 p95 ≤0.15 m/s、关节最大误差 ≤15°、穿地 ≤5 mm；新增支撑皮肤间隙
   p95 ≤5 mm、连续无支撑 ≤50 ms。这些是项目工程验收门，不是生理真实性证明。
2. 默认足底盒改为 SMPL 足部表面凸包。形状对照固定质量、质心和原足底带盒惯量；
   其余部位仍为胶囊，人体自碰撞仍关闭。形状改变后 grounding/参考会重新生成，
   因而对照是整条几何管线的效果，不是冻结参考下的纯形状因果实验。
3. 加入 `record_mesh_at_physics_hz`；同一 pre-step 保存实际控制状态和实际皮肤。
   原 30 Hz 显示采样仍可用于交互。原生 120 Hz 采集可以按世界顶点线性插值对齐到
   50 Hz，不外推，也拒绝 30→50 Hz 上采样。记录方法写入报告和 manifest。
4. 导出必须通过运行、完整记录窗、动作总门、逐动作质量门；失败会话默认不写输出。
   `--diagnostic` 输出 invalid 且不准训练，Sionna 在入口拒收。正常已验收动作映射为 ADL。
   跌倒需要 impact 与低根高/大倾角，不能只看 falling 模式；falling/fallen 合并一次事件。
   `reset_id` 在降采样前分段，避免原地复位或落在两网格帧之间的复位丢失。
5. 增加代码/模型/动作/场景哈希与记录方法；修正 PhysX 材质 average 合成及 physics purpose
   绑定的显式 authoring。补足凸包、浮空假阳性、逐动作稀释、复位、准入及重采样回归。
6. 120 Hz 记录揭示初始/复位皮肤约 −14.8 mm：旧代码把 −15 mm 根施力目标偏置也用于
   出生传送。本轮将出生位置恢复到未加偏置的高度，施力目标仍保留，最终复测已确认修复。
