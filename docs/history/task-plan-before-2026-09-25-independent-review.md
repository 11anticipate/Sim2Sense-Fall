## 方向与判据约定（2026-09-24，用户明确；09-25 补充关键路径）

- **主方向**：SMPL+AMASS 控制人体在 **Isaac Sim** 里完成各种动作。这是实际使用的内容。
- **最终目的**：识别摔倒。数据链路 = Isaac 运动真值（mesh 序列）→ Sionna RT → CIR 样本
  → 检测模型 → 报警。**数据生成不依赖自主平衡**——摔倒本来就是目标事件，
  行走/蹲/起的根辅助已声明且记录，足够支撑数据管线；P0-C（自主平衡）是仿真保真度的
  后续研究，不阻塞数据。
- **判据用模拟器实测，不用几何代理。** 不为了「能跑 CPU 测试」牺牲准确性。
  CPU 侧的 dry-run / FK / 几何代理一律降级为**预筛**，不作为验收；与实测冲突时**以实测为准**，
  并在文档里写明代理的失效边界。
- **执行顺序按摔倒数据关键路径重排（09-25）**：P0-B 的摩擦/μ 扫描与 P0-C 是行走质量
  与保真度问题（已定量归因，见 [拖滑与转向审计](docs/slip-and-turn-audit.md)），
  保留为数据质量整改，但**不再排在数据管线之前**。
- 本轮反面教材见 [支撑掩码审计](docs/support-mask-audit.md)（几何代理把**参考**当身体量，
  夸大了误报、没抓到主症）与其修正 [掩码对实测接触](docs/mask-vs-contact-audit.md)。

## 本轮需求与范围

- 保留键盘前进、后退、转向、停止及显式复位；新增动作仅为**蹲下、起立、摔倒**。
- 起立先按“从蹲姿恢复站立”实现。摔倒后从地面自主起身属于不同控制任务，暂不自动纳入；R 仍为显式复位，不能称为起立动作。
- 人物路线由用户键盘控制；不实现主动避障、寻路或自动导航。
- 场景交互仍须保持墙体/家具阻挡、地面支撑、真实接触及穿透检查，手动驾驶不免除这些验收。
- 新增用户实测缺陷：正常行走时左手摆臂较正常，右手感觉异常。**已独立复现并定位（09-24）**：
  源 AMASS 窗口内右臂本身摆幅偏小；管线各级忠实传递（PhysX 实际与目标偏差 < 0.1°）。
  **修复方向 2（换源序列）已实施**，CPU 层肩/肘比大幅改善，但实跑层分段复算
  仍未达门槛（前进肩比 0.516 / 门槛 0.75，肘比 0.292 / 门槛 0.55），第 4 项**未通过**；
  跳变与扭转两项已通过。见 [右臂摆动审计](docs/arm-swing-audit.md)。
- 新增用户实测缺陷（09-25）：**行走时脚一直在滑动**；**原地按 A/D 不抬脚、双脚贴地像滑冰转向**。
  已归因并修复第一项的参考侧主因（贴地拖行 → `bake_swing_clearance` 抬脚烤进参考），
  第二项已实现抬脚转向（`turn` 参考步态 + 控制器 turning 模式）；证据见 09-25 执行记录。
- 拳击、坐椅、搬物、抓握、蹲行和额外动作库不属于本轮新增能力；历史试验只作为失败/对照证据。
- SMPL 为主人体模型，AMASS 提供动作参考；PhysX 积分关节驱动、外力、重力与碰撞。

## 验收规则

- 保留已有阈值：受控动作最大关节误差 ≤15°；皮肤穿地 ≤5 mm；有效静态地面脚接触滑速 p95 ≤0.15 m/s。
  滑速按接触点的 `v_COM + omega × (point - COM_world)` 切向分量统计，最小冲量 0.01 Ns。
- 墙/家具穿透深度及持续时间、摆臂接缝、动作过渡和平衡门槛在试验前确定并写入配置，不按结果放宽。
- 跌倒后的关节轨迹不强制满足站姿跟踪门槛；被障碍阻挡也需单独评估接触响应，不能混成通畅动作成功率。
- 每项包含实际截图/录屏和状态数值；参考预览、离线记录渲染、实时视口截图注明各自来源。
- 记录数据/模型/控制器版本与哈希、场景、seed、指标定义；当前固定公寓 smoke 无训练/测试划分。
- CPU dry-run 先行；实现阶段按 AGENTS.md 执行 compileall、pytest、Ruff。涉及场景再做导出和重力正向对照。
- 完成一项即同步本计划、`docs/progress.md` 和对应指南/研究笔记；失败与未测如实保留。
