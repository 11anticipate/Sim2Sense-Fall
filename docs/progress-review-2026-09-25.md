## 2. 浮空的证据与因果边界

**确定的验收缺陷**：`keyboard.py` 的 `skin_ground_clearance` 只判断全会话最小 Z ≥ −5 mm。这是单向穿地门，整个人漂在地上方也能通过。当前报告确实 `skin_ground_clearance=true`。应把穿地、支撑脚离地、双脚无有效接触时长拆开，并按动作/相位分段。

**确定的力学事实**：根辅助直接对骨盆施加位置弹簧、阻尼、重力补偿与姿态力矩；当前重力补偿为 0.7、向上力上限为 1.0 体重。实测前进仍由根部举走约 73% 体重。它是受外力扶持的动力学人体，并无自主平衡证明。

**确定的几何脱节**：碰撞体有有效脚接触时，可见皮肤仍整体离地。脚底薄盒减少了包络，但盒角、接触偏置及刚性足盒与变形蒙皮之间仍会有差异；改为薄盒同时改变了质心和惯量，不能把改善全归给碰撞几何。下一轮应逐脚叠加实际碰撞盒、接触点和实际蒙皮，测量随踝角变化的间隙。不能仅凭本轮观测把每毫米间隙精确分摊给辅助或盒角。

**已有修复只部分有效**：重新读取 `plant_ab/shipped` 与 `float_fix/z015`，纯前进离地 p95 为 31.55→21.67 mm，修复后仍有 86.8% mesh 帧整体 >10 mm。它与当前独立运行一致。历史全会话滑速 0.203→0.236，说明下压身体有接触/滑动代价；不能直接继续增加下沉量或摩擦。

**方向合理**：SMPL 定义体表、AMASS 提供参考、PhysX 提供运动/接触、Sionna 映射无线变化，是可研究的系统分层；使用辅助控制生成数据本身并非错误，也不必把从地面自主起身或导航加入当前范围。

**研究缺口**：是否能用于跌倒识别，取决于辅助对正常动作与摔倒的几何/速度分布、切换瞬态和无线特征的影响。仅声明辅助存在不等于数据质量合格。F 同时撤辅助和撤关节驱动，主要覆盖外推力被动倒地；模型可能学到控制切换或正常动作缺陷。后续需多种原因/方向/体型、快速下蹲/坐下/躺下等混淆活动及真实数据外部验证；混淆活动作为后续数据需求，不扩大本轮键盘动作范围。

**不宜给单一完成百分比**：一个 CIR smoke、一个脚接触控制器与完整跨域检测并非等价工作量。建议用“已实现 / 实测通过 / 证据可用 / 未测或失败”四列维护阶段状态。

## 5. 推荐顺序（方案建议，尚未实施）

1. 冻结当前配置、源动作与场景；预先定义逐脚皮肤间隙、接触占空比/无支撑时长、载荷比例、分动作滑速、穿透和过渡指标。阈值通过原始动作/几何容差及使用要求制定，不因本次结果放宽。
2. 先分离碰撞包络、接触偏置、足部惯量与根辅助的影响。当前碰撞拟合会一起改变质心/惯量，应固定其他因素做单变量对照；提供脚底近景和状态叠加。
3. 比较当前辅助 PD 与接触感知全身控制的最小站立/前进行走方案。根轨迹、支撑脚速度、承重及关节驱动必须协调；仅调一个 μ 或继续下压根部已有回归证据。自主平衡可作为独立研究，但足底接触质量不能因而延期。
4. 补 W/S、W+A/D、起停、C/V/F、受阻的统一矩阵，再做 10 分钟交互。原地 A/D 继续禁用；分别报告辅助水平和受阻行为。
5. 修正数据准入/标签/复位边界、50 Hz 对齐和场景一致性后，恢复极小物理公寓 CIR 验收包并保存摘要/哈希。此后才批量生成、隔离人物/源序列/场景、训练基线及报告事件召回、每小时误报和延迟。
