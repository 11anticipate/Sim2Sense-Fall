# 键盘控制与实时物理显示

维护日期：2026-09-24。[文档索引](README.md) · [当前计划](../task_plan.md)。

## 启动与键位

从任意目录执行：

```bash
~/isaacsim/python.sh /home/gsh/Documents/室内摔倒与机器人救援/scripts/humans/keyboard.py
```

等待人体与窗口出现，点一下 Isaac 窗口获得焦点。默认速度 0.4 m/s，转速 30°/s。
窗口中的 `External root assistance: ON` 表示当前使用外力辅助。

| 按键 | 动作 |
| --- | --- |
| W / 上箭头 | 向人物朝向前进 |
| S / 下箭头 | 后退 |
| A / 左箭头 | 左转，可与前后移动同时按 |
| D / 右箭头 | 右转，可与前后移动同时按 |
| 空格 / 松开方向键 | 减速停止并恢复站姿 |
| R | 复位到初始位置，清零速度；这是显式传送 |
| Esc / 关闭窗口 | 退出并保存记录 |

默认输出 `artifacts/humans/keyboard/`。重复运行会覆盖该目录同名产物，可用 `--out` 区分。
`control.npz` 为物理状态、目标、外力和输入，`contacts.json` 为逐帧接触对象/点/冲量，
`recording.npz` 为实际物理姿态蒙皮，`report.json` 为来源和质量门槛。
内存采用有界历史，默认保留最近约 120 s 的控制与显示记录；长时间使用不会无限累计网格。
报告的质量指标仅覆盖保留时间窗，不代表整段任意长会话全部通过。

CPU 和自动 GUI 测试：

```bash
python3 scripts/humans/keyboard.py --dry-run --out artifacts/keyboard_control_20260924/cpu
~/isaacsim/python.sh scripts/humans/keyboard.py --demo --capture \
  --out artifacts/keyboard_control_20260924/gui
# --headless 可改为无窗口自动测试；--seconds 可限定运行时长
```

此入口目前支持移动、转向、站立及复位。计划只新增蹲下、从蹲姿起立和摔倒，尚未配置这些键位。
路线由用户键盘控制，不实现主动避障；碰撞阻挡和接触质量仍须验收。R 是复位传送，不是起立动作。

## 工作目标

用键盘驱动物理关节目标和有界根外力，让 SMPL 显示实时 PhysX 姿态。
普通移动、转向和停止不写入根位姿，不绕过墙体碰撞。
先交付明确标记为辅助控制的工具，自主平衡继续作为独立未完成能力。

## 调查记录

- 当前 `HumanRuntime` 已有关节位置/速度目标、根外力及实际连杆姿态读取。
- `app.update()` 会推进物理，不能与手动步进混用而忽略额外步数。
- 旧显示函数每帧重写拓扑；已改为预创建显示网格、仅更新点坐标，并通过 GUI 复位试验。
- 实验产物保存在 `artifacts/keyboard_control_20260924/`，参考源/配置/seed 随报告记录。

## 已实现

- `scripts/humans/keyboard.py`：独立 GUI 入口，`--dry-run` 可不启动 Isaac。
- `src/sim2sense_fall/humans/teleop.py`：CPU 可测试的按键状态、步态周期化、限速和平滑过渡。
- `configs/humans/keyboard.yaml`：AMASS 源区间、出生点、速度、相机和验收阈值。
- `W/S` 或上/下键前进后退，`A/D` 或左/右键转向，空格制动，`R` 复位，Esc 退出。
  松键减速站立，窗口失焦清除按键状态。复位是显式传送；普通移动不写位姿。
- 通过实际 `PHYSICS_PRE_STEP` 回调施加位置/速度目标和有界根外力，
  UI 更新引起的每一步都有控制，避免手动步进和 `app.update()` 双重计时。
- 预创建拓扑、只更新显示网格顶点；GUI 实时姿态来自 PhysX 连杆，不再等待试验结束回放。
- 自动 demo 经 `carb.input.InputProvider` 缓冲键盘事件，再由正常订阅回调处理；
  它验证实际事件队列，不等同于人工手按键盘的主观体验测试。
- `report.json` 分开记录运行完成与动作质量门槛。接触点切向速度使用
  `v_COM + omega x (contact - COM_world)`，仅对静态 floor、有有效冲量的脚部接触计算；
  不把踝关节平移速度误当接触滑动，不把这个量应用于动态家具。

## 已发现的问题

- **待诊断：右臂摆动异常。** 用户人工键盘行走时观察到左手较正常、右手感觉异常。
  当前没有专门的左右臂对照测量，不能归因于相机、AMASS 本身或右肩轴错误。
  下一步对照原片段、循环目标、PhysX 实际肩肘腕及蒙皮，用多视角连续画面定位；见计划 P0-A。

- 初次相机更新的 USD edit target 层错误，导致重复 transform op；改为会话层后正常。
- `demo_v2` 实际撞到沙发；随后通畅路线和挡墙负对照分开验证。
- 旧 idle 源第 6.9 s 是 AMASS 采集 T-pose，截图发现后改为 3.4 s 自然站姿。
- 当前循环是 AMASS 片段端点漂移修正后的派生控制参考，不是原始 AMASS 全片严格重放。
- 实际测得接触滑步；还需要支撑脚约束/落脚规划或物理模仿策略。根辅助不能替代自主平衡。

## 2026-09-24 实测

最终动作配置为 `keyboard.yaml` + `human_smpl_multiaxis.yaml` + `root_assist.yaml`。
数据源为本地 `Transitions_mocap/mazen_c3d/walkbackwards_stand_poses.npz`，
前进片段 3.9167–4.9583 s，后退片段 0.8–1.5917 s，站姿取 3.4 s。
保留源躯干倾斜，用户控制世界偏航；步态接缝修正、速度缩放和平滑均属派生参考。
SMPL neutral v1.1.0、seed=20260922、固定公寓、无训练/测试集划分，
Isaac 6.0.1-rc.7 / RTX 4060。源动作、人体模型、配置和场景 SHA-256 见报告。

`artifacts/keyboard_control_20260924/gui_tilt/report.json`：

- GUI 连续运行 10.3 s 仿真时间，1236 物理步 = 1236 控制回调，1 次按键复位，无张量失效。
- 正常前进阶段移动 1.098 m；制动后 4.8–5.0 s 水平速度最高 0.0276 m/s。
- 按左转 1.5 s 时已完成约 39.87° 偏航，后续惯性减速继续收敛；后退、停止、复位截图已查看。
- 最大关节误差 13.787°，通过配置的 15° 门槛；根外力峰值 759.8 N。
- 最低皮肤 Z=-9.86 mm，超过 5 mm 容限；脚部有效接触的切向速度 p95=0.751 m/s，
  超过 0.15 m/s 门槛，约 67.7% 样本超限。这个统计含站立、转向与移动整个流程，
  不是连续无滑步。`motion_accuracy_accepted=false` 如实保留。
- 309 帧真实网格记录，8 张运行期间的视口截图。约 23 s 墙钟时间对应 10.3 s 仿真，
  当前可交互，但本机渲染下未达到稳定 1 倍实时速度；配置渲染频率不能当作实测帧率。

`artifacts/keyboard_control_20260924/barrier/report.json`：

- 同样通过实际按键事件队列执行，相同 1236 步，复位正常。
- 独立挡墙场景来自前轮 `artifacts/amass_audit_20260924/barrier.usda`，墙近侧 Y=2.49 m。
  人体根最大 Y=2.355 m，没有按键传送穿过墙。最大根目标偏离严格限制在 0.10 m。
- 2836 个墙接触报告点，其中 1599 个冲量 > 0.01 Ns，峰值 15.223 Ns。
  被阻挡时最大关节误差升为 22.256°，不能当作动作跟踪成功。
- 皮肤沿墙法线最大越界约 51.2 mm。这是碰撞代理与皮肤不贴合的剩余问题，
  根被挡住不等于所有皮肤顶点不穿墙。
